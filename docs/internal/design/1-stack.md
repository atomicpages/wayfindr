# §1 Stack

Part of the [Wayfindr technical design](../design.md). Go code cites this file
as "design §1".

| Concern         | Choice                                                                                                  | Notes                                                                                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Language        | Go 1.26                                                                                                 | `modernc.org/sqlite` requires Go 1.26.                                                                                                                                  |
| Module          | `github.com/atomicpages/wayfindr`                                                                       | Everything lives under `internal/`, so there is no public Go API.                                                                                                       |
| MCP             | `github.com/modelcontextprotocol/go-sdk` v1.8.x                                                         | Server and client. Supports 2024-11-05 through 2026-07-28.                                                                                                              |
| CLI             | `github.com/spf13/cobra`                                                                                |                                                                                                                                                                         |
| Config          | `github.com/BurntSushi/toml`                                                                            | Strict: `MetaData.Undecoded()` makes unknown keys an error.                                                                                                             |
| Config watch    | `github.com/fsnotify/fsnotify`                                                                          |                                                                                                                                                                         |
| SQLite          | `modernc.org/sqlite`                                                                                    | Pure Go. Pin `modernc.org/libc` to the version it requires.                                                                                                             |
| Postgres        | `github.com/jackc/pgx/v5` and `github.com/pgvector/pgvector-go/pgx`                                     |                                                                                                                                                                         |
| OAuth           | `golang.org/x/oauth2` plus go-sdk `oauthex` helpers                                                     | The SDK's `AuthorizationCodeHandler` is not used ([§7](../design.md)).                                                                                                  |
| JSON Schema     | `github.com/santhosh-tekuri/jsonschema/v6`                                                              | Remote refs off; formats not asserted.                                                                                                                                  |
| Keychain        | `github.com/zalando/go-keyring`                                                                         | No cgo.                                                                                                                                                                 |
| Logging         | `github.com/rs/zerolog`                                                                                 |                                                                                                                                                                         |
| Terminal input  | `golang.org/x/term`                                                                                     | `wayfindr secret set` reads the value without echo on a TTY; `connector tools <connector> <tool>` reads the terminal's width.                                                                                                            |
| IDs             | `github.com/google/uuid` (`NewV7`; `New`, v4, for the telemetry install ID)                             |                                                                                                                                                                         |
| Single-flight   | `golang.org/x/sync/singleflight`                                                                        |                                                                                                                                                                         |
| LRU             | `github.com/hashicorp/golang-lru/v2`                                                                    | Query-embedding cache.                                                                                                                                                  |
| Goroutine leaks | `go.uber.org/goleak`                                                                                    | Tests only: the daemon integration test ([§7.8](7.8-daemon.md)).                                                                                                        |
| OS calls        | `golang.org/x/sys`                                                                                      | `daemonlock`'s file lock: `flock` on Unix, `LockFileEx` on Windows. Windows: process groups and detach (`upstream`, `daemonctl`), Winsock errnos (`httpd`, `upstream`). |
| Test diffs      | `github.com/google/go-cmp`                                                                              | Tests only: structural comparison (CODING_STANDARDS: Tests).                                                                                                            |
| Web console     | htmx 2.0.4, Geist and Geist Mono (vendored, embedded); theSVG slug list (embedded, logos from jsDelivr) | Not Go modules: files under `internal/webui/static`, licenses and the htmx checksum in its `CREDITS` (ADR 0016, 0019).                                                  |
